# 思源 MCP 工作流 Skill

面向思源笔记（SiYuan Note）的 MCP 优先工作流 Skill。

它不提供另一套思源 CLI、API 客户端、向量索引、向量数据库集成或凭据配置。这些属于已连接的 MCP 服务职责。Skill 负责定义让 Agent 稳定、安全地使用 MCP 的工作流程：工具发现、编辑前检索、最小范围的块级修改、写后验证，以及破坏性操作的显式确认。

## 内容

- `skills/siyuan-mcp-workflows/SKILL.md`：可移植的 Skill 定义。

## 工作逻辑

1. 先发现 MCP 服务实际提供的工具和参数，不假设特定 MCP 实现的工具名称。
2. 搜索、读取并确认笔记本、文档或块的真实 ID 后，才进行编辑。
3. 局部修改优先使用块级操作，避免删除并重建文档导致引用、属性和块 ID 丢失。
4. 每次写入后重新读取对应对象，确认内容、位置和元数据符合预期。
5. 删除、批量修改、批量移动、批量替换标签与自动格式化前，先给出范围预览并等待明确确认。
6. 内部链接使用思源块引用；标签和属性优先通过 MCP 的专用工具维护。
7. 不自动同步、格式化或设置图标，这些会改变用户内容或偏好，必须由用户请求。

## 安装

使用 Agent 的 Skill 安装机制安装此目录，然后开启新会话以刷新 Skill 索引。使用前需已配置并连接可用的 SiYuan MCP 服务。

也可以通过 `skills.sh` CLI 安装：

```bash
npx skills add 1001ww/siyuan-mcp-workflows --skill siyuan-mcp-workflows
```

## 适用范围

这是一个仅包含 Skill 的项目，假设你已拥有功能完整的思源 MCP 服务。它规范 MCP 的使用流程，不替代 MCP 服务本身。
